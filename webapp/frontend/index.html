Network scan (nmap)

單一 IP、CIDR 網段、或逗號分隔的多個目標
作業系統指紋辨識（-O）
需要較高權限，會延長掃描時間
先做主機存活探測
預設關閉、假設目標都在線（IoT 裝置常擋 ping）

Firmware scan (binwalk)

解壓縮（-e）
目前不會自動分析解壓縮出來的內容
遞迴掃描（-M）
通常搭配解壓縮使用
以 root 權限執行解壓縮工具
降低一層安全防護，只有以 root 執行本工具且需要解壓縮時才勾選

Web app scan (ZAP)

執行 Active Scan
會送出攻擊性測試請求，只對你有權測試的目標執行；取消勾選則只做 spider
自動啟動 ZAP daemon
偵測不到 daemon 時自動啟動，結束後自動關閉
